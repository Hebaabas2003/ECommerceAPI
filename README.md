# E-Commerce API

A simple E-Commerce REST API built using Python and Flask.

## Features

- User signup and login
- JWT authentication
- View products
- Search products
- Add products to cart
- Remove products from cart
- Separate cart for each user
- Checkout
- Admin product management
- Inventory management
- Stripe test payment integration

## Technologies

- Python
- Flask
- PyJWT
- Stripe API
